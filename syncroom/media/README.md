# Your media folder

Put video files you have the right to play here (or point Settings → My media folder somewhere else).

- Movies: `Title (Year).mp4` — optionally add an IMDb tag: `Title (Year) [tt1234567].mp4`
- Episodes: `Show Name/Season 1/Show Name - S01E02 - Episode.mp4`
- Subtitles: same name + language: `Title (Year).en.srt`, `Title (Year).de.vtt`

Browser-friendly formats: MP4 (H.264/AAC), WebM. MKV works in Chromium browsers when its codecs are supported.
This folder is git-ignored.
